# Logos

- `bipa-symbol.svg`: símbolo colorido (bloco `brand` amarelo, barras em `ink`, laser em `alert`, o coral do laser de um leitor). Uso padrão, inclusive como ícone do app.
- `bipa-symbol-mono.svg`: versão em uma cor, desenhada em `ink` (#1C1B1F), com o laser como uma linha separada das barras por um respiro. Para marca d'água e carimbos; sobre fundo escuro, aplique em `ink` do tema escuro.

Área de respiro mínima: 1/4 da largura do símbolo em todos os lados. Tamanho mínimo: 24px.
